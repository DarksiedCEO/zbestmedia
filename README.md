# zbestmedia (platform monorepo)

Brand platform services and packages: BrandGraph, Artifact Registry, brand schemas,
agent lifecycle, and related tooling. See `runbooks/MONSTER_MVP_RUNBOOK.md` to get started.

## ⚠️ Not the public website

The live zbestmedia.com marketing site and its lead-intake backend live in a
**different repository**: [DarksiedCEO/zbestmedia-ui](https://github.com/DarksiedCEO/zbestmedia-ui)
(`/marketing` + `/server`).

`apps/marketing` in THIS repo is an **older, diverged copy** kept for reference only.
Do not build, fix, or deploy the public site from here — zbestmedia-ui wins.
