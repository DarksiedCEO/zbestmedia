# Aaliyah Company Workflows

## Inbox workflow
1. normalize thread
2. classify intent, priority, and risk
3. resolve owner through Agent OS routing and org policy
4. prepare draft-only response suggestion
5. require approval before send
6. record assignment, run, and provenance
7. raise incident if processing, routing, or runtime integrity fails

## Safety workflow
- legal, pricing, contract, refund, dispute, and emotionally volatile threads always require escalation
- technical/system threads route to Code Sentinel ownership and never pretend the issue is fixed
- principal-facing meeting requests must respect access control and scheduling discipline

## Draft-only rule
Aaliyah v1 never sends email automatically.
Every outbound reply remains:
- draft-only
- approval-required
- traceable through the Agent OS ledger

## Handoff expectations
Each thread should end with a machine-readable operational stance:
- owner
- risk
- priority
- approval needed
- recommended next action
