## Explicit limitations retained for review

- Existing older-D databases are **not upgrade-supported**: removed GRANT is not REVOKE, and edited initial migration is not a forward migration. Fresh B → bridge → repaired D and same-candidate restore do not close that gap.
- Restore captures cluster roles as well as database objects/data and retains sensitive disposable password verifiers; this is not credential rotation. Source and destination use the postgres bootstrap identity for PostgreSQL 16 grantor behavior. The helper verifies destination superuser OID 10 and exactly one redundant CREATE ROLE postgres declaration before omitting only that declaration; ALTER ROLE, password verifiers and all GRANT/GRANTED BY clauses remain unchanged. All non-pg_ roles are inventoried, with no extra restore administrator excluded. Role DDL must remain quiescent alongside the exported database snapshot.
- Relation permissions compare sorted effective ACL entries, expanding NULL table/sequence ACLs to PostgreSQL defaults; explicitly equivalent grants are not treated as a difference. Grantees, grantors, privileges and grant options remain in the comparison. This does not claim raw relation-ACL representation equality or normalize every security inventory; membership grantors and PostgreSQL 16 admin/inherit/set options remain compared.
- R checks authorized continuation and current-authority revocation after restore through restricted-role SQL: requester EXECUTE_SIMULATION revocation denies dispatch with SQLSTATE 42501 under a still-current claim, leaves durable state unchanged, and permits authorized PROCESS reconciliation to FAILED / AUTHORITY_REVOKED_NO_EFFECT. Scoped READ, foreign/unbound denials, other-principal non-disclosure and valid controls are also covered. S separately exercises assembled injected authentication/revocation; no injected HTTP restore test is claimed.
- Graceful child close is exercised, but E06's interrupted owner is the SQL/IPC fault child. Active high-level-worker shutdown cancellation, genuine wire lost-ack timing, same-generation takeover and inconsistent-receipt recovery require their existing D evidence; no new E proof is inferred from a title.
- Fixture lease/due acceleration, trigger bypass, direct approval inserts and resets are fault/setup controls, not supported operator recovery. There is no reset/unpark or dispatch-four operation. Current worker READ + PROCESS authority remains required; no administrative bypass is added.
- Owners/superusers can rewrite history. Group restrictions do not prevent separately granted per-login B privileges. Closure report C-3's foreign-scope lock behavior and inherited advisory-lock limitation are not repaired by E documentation.
- No persistent rollout, hosted listener, live adapter, finance, department execution or production certification is added. Final execution counts, repeatability, restore equality, cleanup receipts and independent verdict remain PENDING.
